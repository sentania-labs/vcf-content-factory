## Vision

- On HostSystem: `cpu|vcpus_allocated_on_all_powered_on_vms` /
  `cpu|corecount_provisioned`. Recon sample: 18 / 12.
- Why: there is no host-level ratio key (recon). Physical cores, no
  hyperthreads, powered-on VMs only, so it is consistent with the native
  cluster ratio.
- Must not divide by zero.
