How the highlight works. A list-view cell can only be coloured by its own value, never by another column. So the plain vCPU:pCore column stays uncoloured, and two super metrics republish the ratio only while the cluster is contended, one per definition of "contended": more than 2.5 % of the cluster's VMs facing CPU ready (the green limit on the stock Cluster Performance scoreboard), and average cluster CPU contention above 5 % (the factory's band). Each is 0 (uncoloured) on a clean cluster, yellow as soon as it fires at any ratio, orange from 3:1 and red from 6:1 (the stock Cluster Capacity ratio bands). cluster-01 at 3.55 stays quiet on both; wld01 at 3.17 lights up on both; cluster-02 fires on ready only. Planned Ratio shows the 3:1 being set in the lab policies today.
