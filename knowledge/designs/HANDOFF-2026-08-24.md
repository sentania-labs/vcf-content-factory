## The through-line

Nearly every defect this session was **one shape**:

> a value meaning *"we do not know"* consumed as if it meant something
> specific and reassuring.

An HTTP error yielding an empty list that feeds a create decision. An
absent `state` member reading as idle. `git check-ignore` exit 128
reading as "not a repository". An absent Ext.Direct `type` reading as
success. A wrong-shape `result` reading as "no content found".

Codified in `knowledge/lessons/unenumerated-exit-status-is-not-a-verdict.md`.
The rule: **enumerate the values you accept; everything else is unknown,
and unknown is never the reassuring branch.**

The second-order lesson, learned three times in one day: **an assertion
that names the right property but tests a proxy for it is not coverage.**
A stub instead of the function. A method name instead of the receiver. A
string's presence in source instead of the branch executing. Each passed
green while the defect was live. Negative controls caught all three —
**41 across one branch, none uncaught**.

## Operational notes worth keeping

- **Verify inside the artifact.** Opening a built zip caught #119 (the
  PowerShell half of #101) that no green build would have surfaced.
- **A dirty tree stopped a rebuild and saved lost work.** An agent died
  leaving uncommitted changes in the main checkout; they rode through
  several branch switches and survived only because nothing conflicted.
  The packager's refusal to stash files outside its mandate is what
  surfaced them.
- **State the denominator with the count.** Two sweeps had correct
  conclusions and wrong arithmetic (15-vs-19 loops, 3-of-30 vs 3-of-25).
  A number that cannot be checked against a stated scope is not evidence.
- The dist repo must be clean, on `main`, and **not behind origin**
  before `/publish`, or the CLI refuses. A `--ff-only` pull is the fix.
- `dist/bundles/` holds inert leftovers from an older layout; current
  builds land at `dist/<name>.zip`.
- **Open the PR when you commit the branch.** Work parked on a local
  branch reads as done in a transcript and is invisible everywhere else.
  Twice this session that bit: an agent's uncommitted changes nearly lost
  to branch switches, and a merge-ready docs branch sitting for hours
  with an issue pointing at it.
