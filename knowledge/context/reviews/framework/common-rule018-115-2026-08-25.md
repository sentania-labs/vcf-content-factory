## Change under review

Removes the three native-Windows branches from factory code that
RULE-018 (`knowledge/rules/posix-only.md`) forbids, per issue #115:

- `src/vcfops_common/doctor.py`: `venv_python()` drops the
  `Scripts/python.exe` probe; module docstring now states POSIX only;
  bootstrap checklist message drops the pointer to issue #89 (verified
  CLOSED) and the Windows-port caveat.
- `src/vcfops_common/setup_credentials.py`: the `os.name == "nt"`
  guard around the tmp-file `os.chmod` is removed (chmod now runs
  unconditionally inside the pre-existing `try/except OSError`); the
  closing message drops its Windows caveat; docstrings corrected
  (module header, `write_env_file`).
- `tests/test_common_setup.py`: two `skipif(os.name == "nt")`
  decorators removed; commit 3842e7e (fold-in of this review's NIT)
  adds `test_write_env_file_survives_a_raising_chmod`.

No other files in the diff (`git diff --stat`: 3 files, +12/-25;
commit 3842e7e adds +23 lines to tests/test_common_setup.py only).
